# Joker — онлайн-инфраструктура (Supabase + GitHub + Яндекс Игры)

## Файлы
- `supabase_schema.sql` — вся база данных: профили, монеты, скины, лиги, джекпот, столы, история. Вставить целиком в Supabase → SQL Editor → Run.
- `yandex-sdk.js` — обёртка над Yandex Games SDK (игрок, реклама, лидерборды, покупки).
- `supabase-client.js` — обёртка над Supabase (профиль, монеты, скины, столы, реалтайм).
- `.github/workflows/build-yandex-zip.yml` — при пуше в `main` сам собирает зип для загрузки в кабинет разработчика.

## Шаги настройки

### 1. Supabase
1. Зайти на supabase.com → New project.
2. Project Settings → API — скопировать `Project URL` и `anon public` ключ.
3. SQL Editor → вставить содержимое `supabase_schema.sql` → Run.
4. Вписать URL и ключ в `supabase-client.js` (`SUPABASE_URL`, `SUPABASE_ANON_KEY`).

Важно: `service_role` ключ **никогда** не класть в клиентский код — только `anon`. Все изменения баланса/скинов идут через `rpc`-функции в схеме, они уже настроены как `security definer` и сами проверяют условия.

### 2. GitHub
1. Создать репозиторий, залить в него игру + эти файлы.
2. Workflow из `.github/workflows/` заработает сам при пуше в `main` — во вкладке Actions появится собранный `yandex-build.zip`.
3. Поправить путь `dist` в workflow на реальную папку с игрой, если сборки как таковой нет.

### 3. Яндекс Игры
1. Разработчикам Яндекс Игр → создать черновик игры.
2. В `index.html` подключить `<script src="https://yandex.ru/games/sdk/v2"></script>` перед своим кодом.
3. Вызвать `initYandexSDK()` при старте и `markGameReady()`, когда экран выбора формата уже показан.
4. В настройках игры (раздел про сеть/хосты) добавить домен твоего Supabase-проекта (`*.supabase.co`) в список разрешённых — иначе запросы к базе будут заблокированы.
5. Загрузить `yandex-build.zip` из GitHub Actions в кабинет разработчика.
